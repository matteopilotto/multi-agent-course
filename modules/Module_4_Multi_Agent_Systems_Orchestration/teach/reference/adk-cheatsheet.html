Skeleton

from google.adk.agents import LlmAgent
from google.adk.runners import Runner
from google.adk.sessions import InMemorySessionService
from google.genai import types

agent    = LlmAgent(name="…", model="gemini-2.5-flash", instruction="…", tools=[…])
sessions = InMemorySessionService()
runner   = Runner(app_name="app", agent=agent, session_service=sessions)

s   = await sessions.create_session(app_name="app", user_id=uid)     # async!
msg = types.Content(role="user", parts=[types.Part(text=text)])
async for event in runner.run_async(user_id=uid, session_id=s.id, new_message=msg):

Tools

  • A plain function in tools=[…] is wrapped as a FunctionTool; its signature + docstring become the schema. Type hint and no default = required. function tools
  • toolbox-core: await ToolboxClient(url).load_toolset(name, bound_params={…}) returns callables ADK wraps directly. A bound parameter is removed from the signature and docstring, so it's absent from the model's schema; the value is added to every call.
  • ADK's docs use ToolboxToolset from toolbox-adk (pip install google-adk[toolbox]), same idea. ADK + Toolbox

Gotchas

  • create_session is a coroutine: forget await and you get a coroutine object, not a session.
  • run_async on a missing session raises SessionNotFoundError (unless Runner(auto_create_session=True)).
  • Toolbox results arrive as {"result": "<JSON string>"}. "[]" is truthy. Decode before testing.
  • Peek at the exact model-visible schema: FunctionTool(tool)._get_declaration() (private; debugging only).
